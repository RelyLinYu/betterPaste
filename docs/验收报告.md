## 已知限制（诚实记录）

1. **极速连续复制的采样上限**：轮询周期 60ms。人类手速（≥150ms/次）实测 100% 捕获；但以脚本灌入 40–80ms/次时只能采到一部分。这是"序号轮询"方案的固有上限，要彻底解决需改用 `AddClipboardFormatListener` 事件驱动（需自建消息窗口），不在 MVP 范围。
2. **文本体积上限与图片共用** `单条体积上限`（默认 10MB）；超限的文本会被忽略而非截断。
3. **置顶条目豁免清理**：条数与天数上限都不会删除置顶条目（这是刻意的——用户手动钉住的内容不该被后台任务删掉）。
4. **管理端反作弊/游戏内窗口**：模拟按键在部分受保护窗口里会被忽略，此时走 `manualFallback` 提示。

## 测试与诊断工具（都留在仓库里）

```powershell
# 查看历史 / 搜索 / 性能基准
clipstack.exe --probe                        # 最近 20 条
clipstack.exe --probe "关键词"                # 搜索并统计匹配数
clipstack.exe --probe "关键词" --bench 30     # 重复 30 次并打印 min/中位/平均/max

# 直接操作置顶槽（便于脚本化验证）
clipstack.exe --ctl pin 3 "某段文本"
clipstack.exe --ctl unpin 3

# 直接亮出窗口（绕过单实例，便于截图/调试）
clipstack.exe --overlay
clipstack.exe --settings

# Rust 单元测试（25 个，覆盖搜索/清理/热键解析/剪贴板时序状态机）
cargo test --lib
```
